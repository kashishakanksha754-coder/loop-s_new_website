03 — Spacing

An 8px rhythm, consolidated gaps.

Everything sits on an 8px vertical grid. Between major sections the visible gap is ~96px desktop / ~64px tablet / ~48px mobile. When a section's bottom padding meets the next section's top padding, consolidate — the visible gap equals the target, never the sum.

05 — Motion

Subtle, always.

Fade + small translate on scroll-in. Smooth transitions on every interactive element. Nothing flashy. All motion respects prefers-reduced-motion.

Scroll reveal

opacity 0→1, translateY 16→0, 0.7s ease-out.

Hover

color + transform, 200–300ms transitions.

Reduced motion

All animation disabled when the user prefers it.
